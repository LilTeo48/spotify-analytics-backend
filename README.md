# Spotify Analytics Backend

A FastAPI backend that simulates Spotify streaming analytics data.

## Features
- Top artists endpoint
- Top tracks endpoint
- Top genres endpoint
- Listening summary endpoint
- Interactive Swagger API docs

## Tech Stack
- Python
- FastAPI
- Uvicorn
- Git/GitHub

## Run Locally

```bash
pip3 install fastapi uvicorn
uvicorn main:app --reload
